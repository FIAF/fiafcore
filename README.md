
# FIAFcore

The FIAFcore ontology is an ontology for film archives, developed to enable the federation of filmographic data from disparate sources. It is heavily based on the language and structures of the [FIAF Cataloguing Manual](https://www.fiafnet.org/pages/e-resources/cataloguing-manual.html).
